# Controls

## Core
- Space: pause
- R: reset
- T: thermal overlay

## Ship
- WASD thrust vector
- Q/E roll
- Shift boost

## Camera/tool shortcuts
- F, O, G, H, C, V

## UI tools
- Brush/spray/line/box/sphere fill
- Force, vortex, gravity well
- Heat/cool, vacuum, weld
- Explosion, laser, spawn ship
