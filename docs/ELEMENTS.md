# Elements

Data-driven registry includes 150+ elements across:
- Core materials
- Metals
- Volatiles
- Gases
- Energetics
- Space
- Fictional sci-fi

Each element includes:
- stable ID and key
- category/tags
- render profile
- physical + thermal properties
- phase thresholds and latent heats
- UI metadata (icon, description, warnings)

Reaction system is deterministic and bounded with cooldowns and per-step reaction caps.
